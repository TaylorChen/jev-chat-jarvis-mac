### 4/7（197/280）

```
生成的候选不直接给你，先丢回当前判断后端排序——API 经常混进踩雷选项。

### 5/7（268/280）

```

唯一一次写入是点「填入」，写完会读回来确认，不会自动发送。配置云端 Jev 或生成层时，聊天文字会发往用户指定的服务；两层都可选本地方案。

## 发布细节

- **图片就是封面**：四个编号直接标出固定会话、历史消息、模型设置和数据库上下文；会话与消息内容已替换为示例。
- **标签别多**：1–2 个足够（`#开源` `#macOS`）。堆标签在中文推特上像营销号，反而压触达。
- **时间**：北京时间工作日 **12:00–13:00** 或 **21:00–23:00**，中文开发者最活跃。
- **转发靠哪句**：「真实 100 条上下文」和「不注入、不自动发送」是当前最有辨识度的两点，不要再使用「零封号风险」这种无法验证的绝对表述。
- **先发 thread**：想试水可以先发单条版，数据还行再补 thread（X 上「追一条」比改主贴有效）。
- **有人问隐私边界**：直接回第 5 条那一段——只面向本人设备和本人账号；主应用不注入、不自动发送；配置远程模型后文字会发往用户指定端点；密钥提取涉及一次显式重签。
